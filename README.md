# MediBridge

A healthcare and emergency response platform designed to connect users with essential medical services quickly and efficiently.

## 🌐 Live Website

👉 **[Visit MediBridge](https://medibrideg.netlify.app/)**

## 🚑 Features

- Emergency SOS
- Hospital and facility information
- Emergency contacts
- User dashboard
- Emergency history
- Healthcare assistance
- Responsive web interface
